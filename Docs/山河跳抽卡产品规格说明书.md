## 第一部分 · 产品概念

### 1. 产品定位

- **一句话**：一个"诚实的抽卡问卦"自我探索工具——用动物成语卡每天问一个问题，AI 给启发式解读；抽过的卡解锁进图鉴，可随时回看。
- **诚实路线**：是"镜子"不是"天机"。明说是自我反思工具，不承诺预测、不制造焦虑、不诱导付费。
- **哲学**：占卜 = 把复杂的人类处境降维投影到有限符号，再由"人心"展开成意义。我们不预测命运，我们帮用户在符号里看见自己。

### 2. 双图鉴系统（核心设计）

产品有两个并行的图鉴，互相喂养：

| | **外图鉴 · 成语卡** | **内图鉴 · 声音卡** |
|---|---|---|
| 收集的是 | 外部符号（我遇见过什么） | 内在声音（我如何被改变） |
| 数量 | 49 张（7×7） | 16 张（4 属性 × 4 声音） |
| 解锁方式 | 抽到该成语卡 | 被对应成语卡"喂养"达到阈值 |
| 驱动 | 收集欲 | 养成欲 |
| 变化 | 卡背 → 点亮卡面 | 沉睡 → 唤醒说话 |

**双系统飞轮**：解卦 → 外图鉴+1（新卡点亮）+ 内图鉴喂养（声音数值变化）→ 状态回流决定下次解读"哪个声音说话" → 明日再来（收集+养成双驱动）。

### 3. 内在声音图鉴系统（重点 · v0.3 新增）

#### 3.1 设计灵感

致敬《极乐迪斯科》的"技能系统"——每个技能是一个内心声音，数值越高越频繁地替你说话。我们借其机制，用自己的命名、自己的文案、自己的视觉（版权边界：不直接使用"天人感应/内陆帝国"等原名）。

#### 3.2 四属性 × 十六声音

| 属性 | 内心声音（我们命名） | 喂养它的成语卡类型 |
|---|---|---|
| **智识** | 推理、记忆、辩才、审美 | 逻辑思辨型、典故型成语 |
| **神思** | **感应、灵视**、坚忍、感召 | 神秘型、蛰伏型、登顶型成语 |
| **心体** | 身体、本能、痛感、忍耐 | 困境型、生存型、蓄力型成语 |
| **应物** | 观察、机巧、沉着、警觉 | 关系型、博弈型、备患型成语 |

#### 3.3 唤醒机制

- 初始：16 张声音卡全部"沉睡"（灰色卡背）。
- 每次解卦，成语卡携带一个"声音向量"（预设）：
  - 例：**独占鳌头** → 感召 +3、坚忍 +2、感应 +1
  - 例：**龙困浅水** → 忍耐 +3、灵视 +2
  - 例：**浴火凤凰** → 灵视 +2、感应 +2、坚忍 +1
  - 例：**狡兔三窟** → 警觉 +3、机巧 +2
- 当某声音数值首次 > 0（即被喂养到）→ 该声音卡被**唤醒**（灰色卡背翻转为彩色声音卡）。
- **重复卡同样加 voiceDelta**：数值是状态累积，新卡点亮图鉴，旧卡继续喂养声音，两者职责不同。
- **封顶 100**：`value = min(100, value + delta)`。49 张全抽完最高约 25 点（感召），封顶防止长期重复抽卡后数值溢出 0–100 区间。
- MVP 阶段**不做数值衰减**（不抽也不归零），避免焦虑设计。

#### 3.4 声音卡内容

每张声音卡解锁后展示：
- 卡名（如"感应"）
- 所属属性
- 一句话 tagline（这个声音是谁）
- 当前活跃度（数值，0–100）
- **独白文本**（极乐迪斯科调性：第二人称、感官化、神秘、不承诺但有回响）

**16 张声音卡独白（v0.4 已全部完成，数据源 `voices.json`）：**

**智识**

> **推理 · 把线拉直的人**：先把情绪放下，它不属于这张桌子。你看——你说的三个理由里，有两个是同一个，第三件才是真的。把线拉直：谁先说了谎，谁从中得利，谁现在最怕你想明白。你已经快摸到了，再往下一寸。

> **记忆 · 坐在你身后的人**：它没走。你以为关了抽屉的东西，其实一直坐在你后面那把椅子上。你现在走到的这个岔路口，三年前那个下午已经来过——当时你拐了左边，身体替你记着那一脚刹车的疼。今天，它想让你看清。

> **辩才 · 替你开门的人**：那句话在你舌头上站了很久了，穿着鞋，等你开门。你不让它走，它就从里面敲你，咚咚咚，把你敲得失眠。你有嘴巴不是为了替这个世界保持安静。说。说得不好也没关系，先说出第一句。

> **审美 · 替你摆好分寸的人**：等等。先别问它有没有用。你看它的形状——这段日子你把日子过得太潦草了，连缝都没对齐。好的东西讲究分寸：留白、呼吸、不多不少。你现在缺的不是力气，是把眼前这堆东西重新摆好看的耐心。

**神思**

> **感应 · 替你听风的人**：风从巷子口拐进来，带着昨夜雨水的味道。它在说什么？你听。它在说——你被遗忘的那件事，会在周五回来。它会敲门。

> **灵视 · 看见呼吸的人**：房间里有什么东西在呼吸。不是你。是那件你一直没做的事，它在替你呼吸。它已经等了很久，还愿意再等一会儿。

> **坚忍 · 守着那盏灯的人**：湿透了。但你还站着。别人看到的是你还没走过去，我看到的是你没倒下去。不用起身，也不用再往前一步，就这么站着——火苗在你身上，你不倒，它就不灭。

> **感召 · 你身上最亮的那部分**：你是这个房间里最亮的东西。别人还没发现。没关系，他们很快就会发现。

**心体**

> **身体 · 替你喊疼的骨头**：我喊你三天了。你用脑子压我，用咖啡堵我，用「再撑一下」糊弄我。现在我正式告诉你：这副肩膀是你的，不是那块石头的。去躺下，把手摊开，眼睛闭上。天大的事，也等这块骨头歇完再谈。

> **本能 · 比你早三秒的人**：别分析了。你推门进来的那一秒，后颈就已经绷紧了——它比你所有的聪明都早到三秒。它从不解释，也不撒谎，只是在你不肯听的时候，换成更大的动静。现在问你：它想让你走，还是想让你冲？

> **痛感 · 不肯被你安慰的伤口**：我知道你想给这件事起个好听的名字。别。它就叫疼。你绕路、盖布、说「其实也还好」，可我每天都在这儿替你捂着。你今天哪儿也别去，就坐下来，看着我。看清楚了，我才肯开始好——你一直不看，我就一直疼。

> **忍耐 · 在土里长根的人**：你以为你在原地踏步。不是。你是在往下扎根——根在土里的时候，地面上什么都看不见。毛竹前四年只长三厘米，根在地下铺满几百平米，第五年它一天长三十厘米。你现在，是第几年了？

**应物**

> **观察 · 替你看世界的眼睛**：先别说话。你看见没有——他第二次岔开了话题，你问的那句，他没接。窗外那辆车停了四十二分钟。你自己的手在抖，你都没注意。把这些都收进来。世界一直在给你答案，只是你忙着提问，没在看。

> **机巧 · 教你打结的人**：门锁着，你盯着门干什么？窗没锁。墙是空心的。而且——你根本不用出去，你要的是让他们进来。坐下来，我教你打这个结。活路从来不是撞出来的，是绕出来的；你不是没路，你是只认得一种路。

> **沉着 · 让水静下来的人**：慢一点。再慢一点。你看那潭水，越急越浑，什么都照不出来。等它静下来，你的脸、他的牌、整件事的底，全在里面。稳住，让对面先动。他一慌，你就赢了一半。

> **警觉 · 站在你身后的人**：我知道你想相信他。但我站在你身后，替你看着你不看的那一面。那个笑到了眼角就停了，那个承诺缺了一个时间。不是让你防备所有人——是让你别把后背，交给还没验过的风。

> 文案原则：① 全部第二人称、内心声音直接说话；② 每个声音绑定一个固定意象（感应=风、坚忍=灯、忍耐=竹、沉着=水、警觉=身后）；③ 不承诺未来、不评价对错，只给视角和回响；④ 不制造焦虑，痛感/警觉这类"重"声音的落点都在"面对即开始"。

#### 3.5 声音回流影响解读（个性化核心）

活跃度最高的声音作为"主说话者"注入 LLM prompt（§9 直接喂该声音的独白全文），它决定签诗的语气与意象：

| 活跃的声音 | 签诗语气 |
|---|---|
| 感应高 | 环境低语（风、雨、空间） |
| 推理高 | 偈语式、因果分明、重结构 |
| 灵视高 | 梦境、象征、意象跳接 |
| 坚忍高 | 苦寒、守夜、灯与根 |
| 感召高 | 明亮、登高、气势开阔 |
| 警觉高 | 暗处、回头、意象带警示 |
| 身体高 | 筋骨、疲劳、昼夜身体感 |
| 忍耐高 | 蛰伏、土、慢生长 |

**这是真正的个性化**：两个用户抽到同一张卡，因为内在声音不同，解读视角完全不同——不是"记住你名字"，而是"用你内心的声音说话"。

#### 3.6 边界（必须守住）

1. **版权**：机制借鉴，命名/文案/视觉全部原创，可注明"受《极乐迪斯科》启发"。
2. **心理安全**：不做负面状态（无焦虑值/抑郁值），数值只分"哪个声音活跃"，不分好坏。
3. **不刷卦**：每日限 1 次的设计天然防止"数值焦虑"。

**包含：**

> **正逆位已确认（2026-10-27 手册核对）**：手册明牌有正逆位——正位按牌义解；逆位=**提示换一个角度看问题**（不反转吉凶）。MVP 单牌流程已包含正/逆位随机判定（抽牌随机给正/逆）；逆位规则已直接写进 §9 system prompt（"从另一个角度写"），**不另加补丁**。

### 5. 卡牌内容源：动物成语卡（49 张，7×7）

- **数据来源**：✅ 已完成（2026-10-27）。用户拍盒内手册《牌意介绍》，49 张编号（0–48）、成语名、七章分组已录入 `cards.json`（49 条、id 连续、7×7 校验通过）。官方一句话释义见《山河跳_49卡官方释义核对.md》，cards.json 的 meaning 字段为公版改写（未照抄艺术家措辞）。

  - ✅ 成语本身公有领域；抽卡/图鉴机制不受保护
  - ⚠️ 7×7 分组与 0–48 编号叙事：demo 低风险，商业化需注明"灵感来自《山河跳！》"

### 6. 用户流程

1. 打开首页 → 生成匿名 deviceId → 卡背动画区 + 「今日第一卦」
2. 抽卡 → 翻牌动画 → 显示成语卡面（含正/逆位标识）
3. 可选：输入问题
4. 「求签」→ LLM 一次生成 **签诗 + 白话解签**
   - 默认展示：卡面 + 签诗（居中/竖排，古风字体）
   - 「请解签」按钮：点击展开白话解签（默认折叠，保持神秘）
5. **双图鉴同时更新**：成语卡点亮进外图鉴 + 声音数值变化进内图鉴（toast："你的感召 +3" / "声音「灵视」被唤醒"）
6. 引导：「明天再来」

### 9. LLM Prompt 设计（v0.5 签诗版）

> 输出形式：古寺灵签式。默认只展示签诗（含蓄、多义、留白），白话解签折叠，用户主动点「请解签」才展开。一次 LLM 调用同时产出两样，JSON 返回。

**System prompt：**

```
你是一位古老的"动物成语签"解签人，为用户抽中的成语卡撰写签诗。
文风：古寺灵签、《易经》爻辞、唐人绝句，含蓄、多义、留白。

产出两样：

1. poem 签诗：四句七言（或五言），押韵。
   - 把成语的动物、情境、动作、编号位置（0=降生…48=回首）化入诗中，
     但不直接写出成语；
   - 可借《易经》意象（龙、渊、田、天、水、火等），但不写卦名、不下定论；
   - 正位顺势写；逆位从"另一个角度"写（不反转吉凶，写转机/换境）；
   - 诗中不出现现代词、不出现"你应该"、不直接回答"会不会/能不能"；
   - 语气与意象必须贴合用户当前最活跃的内心声音（见下）。

2. interpretation 白话解签：80-150字。
   - 不预测未来、不承诺结果、不制造焦虑、不诱导付费；
   - 像温和的解签人，点出诗里藏着的一个思考方向，话不说满；
   - 第二人称。

严格输出 JSON：{"poem": "句1，句2，句3，句4。", "interpretation": "……"}
```

**User prompt：**

```
抽到「{idiom}」（第{id}张，{animal}），{正位|逆位}
释义：{meaning}
关键词：{keywords}
编号位置：{arc}——{arcDesc}
你内心此刻最活跃的声音是「{voiceName}」，它说：
“{voiceMonologue}”
（这一签的语气与意象跟着这个声音走）
我的问题：{question}
```

- 无问题时 question 用"我今天想知道什么"占位。
- 数据来源：`{idiom}/{animal}/{meaning}/{keywords}/{arc}/{arcDesc}` 取自 cards.json；`{voiceName}/{voiceMonologue}` 取自 voices.json（活跃度最高的声音）。
- 逆位不需要额外补丁——system prompt 已规定"从另一个角度写"。
- 解析 LLM 返回时做容错：JSON 解析失败则按"前四句为诗、其余为解签"切分。

**签诗样例（36 独占鳌头·正位·问财务）：**

> 蛰久鱼龙未易猜，

**多牌阵的分层解读架构（用户第 6 点，产品关键设计）：**

多牌阵不是"N 张牌各解各的"，必须分两轮 LLM 调用：

```
Round 1（薄G · 并行）：每张牌单独出"基础签诗 + 单牌解签"
  ↓ 4-5 个并发请求，每张牌：一首签诗（呼应其牌阵位置语义）+ 80-150 字单牌解读
Round 2（厚G · 综合）：把所有单牌签诗/解签 + 牌阵位置关系喂回 LLM
  ↓ 做组合分析（可再产出一首总签诗）：
     - 事件发展阵：过去→现在→未来 的演化逻辑 + 启示
     - 四大元素阵：地水火风是否失衡（行动强但物质弱？情绪过盛？）
     - 二选一阵：A 长 B 短的权衡 + 第 5 张忠告
```

- Round 1 可并行、可缓存（同一卡号+位置组合可复用），成本低；单牌签诗复用 §9 的签诗 prompt（加位置语义）。
- Round 2 是真正的"牌阵逻辑分析"，必须等所有单牌签诗/解签完成后才能调用。
- 这就是厚 G/薄 G 拆分在多牌场景的自然延伸：薄 G 并行、厚 G 收口。

## 附：设计哲学备忘

- **占卜不是预测，是镜子**。我们卖的不是"知道未来"，是"今天的自己值得被认真看见"。
- **复杂系统分层**：算卦层是确定性算法（AI 能做），解卦层是复杂系统（AI 要设计耦合），应验层是反馈回路（产品在构造它）。
- **诚实路线**：所有文案不制造焦虑、不诱导付费、不承诺改命。这既是伦理，也是 App Store 审核的护身符。
