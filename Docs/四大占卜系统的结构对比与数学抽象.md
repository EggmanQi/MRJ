# 四大占卜系统的结构对比与数学抽象

> 本文档对比易经、塔罗、奇门遁甲、大六壬四个系统的结构异同，并给出可形式化的数学抽象框架。
> 背景：在研究《山河跳！动物成语占卜卡》和《玉匣金鑑東玄牌》时，对"东玄卡牌化"这一创作方向的底层方法论做的分析。

---

## 一、四个系统的结构对比

| | 易经 | 塔罗 | 奇门遁甲 | 大六壬 |
|---|---|---|---|---|
| **符号基数** | 阴阳二爻 | 78张牌 | 干支+门+星+神 | 天将+四课+三传 |
| **状态数** | 64卦×6爻=384 | 78张全排列 | 约1080局（实质18局） | 约720课 |
| **起局方式** | **随机**（揲蓍/铜钱） | **随机**（洗牌抽牌） | **确定性**（按时辰起局） | **确定性**（月将+占时起课） |
| **时间维度** | 弱（之卦暗示变化） | 无 | 强（每时辰换局） | 强（占时决定一切） |
| **空间维度** | 无 | 无 | 强（九宫八方） | 弱（方位在天地盘） |
| **判断依据** | 卦爻辞文本 | 图像象征+位置 | 五行生克+门星神干 | 课传因果链+天将 |
| **本质** | 6位二进制状态机 | 符号矩阵+位置语义 | 时空多图层网格 | 有向因果图 |

---

## 二、本质异同

### 相同点：都是"映射器"

四个系统在数学上做的是同一件事：

```
问题 → [起局函数 f] → 符号配置 → [解读函数 g] → 判断
```

它们都是一个**符号映射系统**：把求问者的混沌状态，通过一套规则压缩成有限个可解读的符号，再由人（或规则）赋予意义。背后共享同一个假设——**"万物相关"（as above, so below）**，即问卦瞬间的符号配置和你问的事之间存在对应关系。

### 三个根本差异

#### 差异1：随机抽样 vs 确定性生成（最核心）

这是易经/塔罗 和 奇门/六壬 之间的分水岭：

- **易经/塔罗**的起局函数 f 是**随机过程**。摇铜钱、洗牌，摇出什么算什么。同一分钟内问十次，可能得到十个完全不同的卦/牌。
- **奇门/六壬**的起局函数 f 是**时间的确定性函数**。同一个时辰内，不管谁问、问什么，局/课是同一个（只是用神不同）。换个时辰，全盘皆变。

这个差异不是技术细节，是**宇宙观的分歧**：
- 随机派相信：**心诚则灵**——问卦那一刻的随机事件，会"捕捉"到求问者的潜意识状态。本质上是**蒙特卡洛采样**。
- 时间派相信：**天人感应**——问卦那一刻，宇宙在时空坐标系里的坐标就是答案。本质上是**查表函数**。

#### 差异2：静态符号 vs 动态系统

- 易经一卦六爻，抽到就定了。塔罗抽到三张牌，摊开就定了。它们是**静态快照**。
- 奇门一局里，天盘随时干转动，八门随时宫飞布，九星随时干落宫，八神随值符排布——它是一个**动态演化系统**，问完之后这个局还在随时间转。
- 六壬更甚——四课三传本身就是一条**时间因果链**（初传=起因，中传=过程，末传=结果），它不是快照，它就是一段叙事。

#### 差异3：文本驱动 vs 关系驱动

- 易经靠**卦爻辞**——每个状态有固定的文本解读（"潜龙勿用"、"利见大人"）。
- 塔罗靠**图像象征**——每个符号有文化共识上的联想。
- 奇门/六壬不靠文本，靠**符号之间的关系**：这个门克不克那个干？这个星落宫是生是克？这个天将临世是吉是凶？判断是一个**关系网络的推理过程**，不是读一段现成的话。

## 三、数学抽象

### 元模型

四个系统都可以统一成这个数学结构：

```
占卜系统 = {
  符号集合 S,           // 有限符号集
  状态空间 Ω,           // 所有可能的配置
  起局函数 f: X → Ω,   // 从输入生成配置
  解读函数 g: Ω × Q → 判断  // 配置+问题 → 答案
}
```

代入四个系统：

| 系统 | S | Ω | f |
|---|---|---|---|
| 易经 | {⚊, ⚋} | 2⁶=64卦，每卦有动爻 | 随机（铜钱6次） |
| 塔罗 | 78张牌 | 牌阵位置的组合 | 随机（洗牌抽取） |
| 奇门 | 10天干+12地支+8门+9星+8神 | 9宫×多层属性 | 时间 t 的确定性函数 |
| 六壬 | 12天将+天地盘+四课+三传 | 约720课体 | 月将+占时的确定性函数 |

在这个元模型里：
- 易经和塔罗 = **随机采样器**
- 奇门和六壬 = **确定性状态机**

### 各系统的具体数学结构

**易经：6维布尔超立方体上的状态转移**
- 64卦 = 6位二进制数（000000 到 111111）
- 动爻 = 某些位被翻转
- 之卦 = 翻转后的新数
- 承乘比应 = 位与位之间的局部关系
- 这就是一个 6 维布尔超立方体上的状态转移，和莱布尼茨看到的二进制同构是数学上严格的。

**塔罗：有限符号系统 + 位置矩阵**
- 78 个符号
- 牌阵 = 位置矩阵
- 类似一个固定大小的张量，每个位置有固定语义（过去/现在/未来、自己/对方/建议……）

**奇门遁甲：9宫 × 5层属性的多图层网格**
- 空间维度：九宫（9个宫位）
- 时间维度：60时辰一局（实质18局）
- 每宫叠加：天盘干、地盘干、门、星、神 = 5层属性
- 判断 = 在这个 9×5 的关系图上跑生克传播（类似贝叶斯网络的因果推理）

**大六壬：7节点有向因果图**
- 四课 = 4个节点
- 三传（初→中→末）= 一条有向路径
- 十二天将 = 节点上的标签
- 本质是一个状态转移图，和马尔可夫链有结构相似性：初传=初始状态，中传=转移，末传=终态

### 真正的障碍：解读函数 g 不可形式化

四个系统可以在 Ω 层抽象，但 g 函数（从符号到判断）才是真正难数学化的部分：

- 易经的 g：把"潜龙勿用"映射到你的具体处境——这是**自然语言的隐喻推理**
- 塔罗的 g：看到三张牌的图像，联想你的感情状态——这是**跨域的模式匹配**
- 奇门的 g：看用神落宫、生克、格局——这是**有规则的推理**，但规则体系庞大到没有唯一标准答案
- 六壬的 g：看三传因果、天将环境——这也是**有规则的推理**，但同样高度依赖解卦者经验

**数学能描述"牌是什么"，但不能描述"牌在你身上意味着什么"。** 后者才是占卜的核心，而它本质上是一个**心理学投射过程**——符号是屏幕，求问者才是那个投影仪。

---

## 四、一句话总结

> 易经是**随机抽一个6位二进制数然后读古诗**，
> 塔罗是**随机抽一张画然后做自由联想**，
> 奇门是**查一个时空坐标系上的多层网络图然后跑生克推理**，
> 六壬是**按时间生成一张有向因果图然后追因溯果**。
>
> 它们在"输出符号配置"这一层可以统一数学化，但"从符号到人生判断"这一层，是心理学和诠释学的领域，不是数学的领域。

---

## 五、对"东玄卡牌化"产品的启示

以《玉匣金鑑》为例：它把奇门/六壬的 Ω（状态空间）压缩成了50张牌（5行×10张），但 g（解读函数）背后那套"古科学逻辑"才是真正需要教的东西——这也是它商业模式是"卖牌+卖课"而不是单纯卖牌的原因。

以《山河跳！》为例：它走的是另一条路——把易经的"取象比类"翻译成动物成语，g 函数被弱化成"读诗/读故事"，门槛极低，但牺牲了奇门/六壬那种可推演的技术深度。
