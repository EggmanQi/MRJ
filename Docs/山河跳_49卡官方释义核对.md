## 关键发现（与我们之前文档的对照）

1. **官方释义极简**：每张卡只有一句中文 aphorism + 一句英文解释，**没有典故、没有卦象、没有编号时间轴推演**。这印证了我们的"薄G/厚G"架构——
   - 薄G（cards.json 静态释义）= 官方这一句话的公版改写，零 token。
   - 厚G（LLM 实时解读）= 我们的四层解码（本义→取象→编号→问题映射），这才是产品要交付的价值。
2. **36 号「独占鳌头」官方释义仅为"成为最优胜者 / a champion"**：之前我们做的元·《陈州粜米》、殿试鳌头、晋卦、九五"飞龙在天"那一大段，**全是我们自己的厚G延伸，不是手册原文**。这是好事——证明 LLM 解读确实能在官方一句话之上长出深度。
3. **33 号「比翼连枝」官方释义为"恩爱得不想分离 / couple deeply attached"**：之前我们拉的水地比卦、"比之匪人""比之无首"也是厚G延伸。
4. **七组结构确认**：第一章~第七章各 7 张，与我们文档里的分组区间（0-6/7-13/.../42-48）完全一致。
5. **0 号无印刷编号**：仅一个圆点开头，它是"龙生九子"，作为整套牌的叙事起点。
6. **编号命名小差异**：手册用「鹬蚌相争」而非成语全称"鹬蚌相争渔翁得利"；「窥一斑而见全豹」；「兔子不食窝边草」（我们之前在小红书案例里见过 21 号）。
